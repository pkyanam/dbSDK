This page has moved into the full documentation.

:::note
The complete guide lives at [docs/getting-started](/docs/getting-started):
installation from a local clone of the [GitHub repository](https://github.com/pkyanam/dbSDK),
choosing an adapter, and your first query. The short version:

```ts
import { createDatabase } from "dbsdk";
import { neon } from "dbsdk/neon";

const db = createDatabase({
  adapter: neon({
    connectionString: process.env.DATABASE_URL,
    transport: "http", // the default; websocket enables transactions
  }),
});

const { rows, rowCount, command } = await db.sql`
  select id, email from users where id = ${userId}
`;

await db.close();
```

Interpolated values become positional bind parameters, never string
splicing. Every adapter returns the same envelope: `rows`, `rowCount`, and
the PostgreSQL command tag when one is reported.

Connecting to Supabase? Remote endpoints verify TLS certificates against
Supabase's private CA by default. Append
`?sslmode=verify-full&sslrootcert=<CA path>` to the connection string from
your project dashboard, or see [docs/adapters/supabase](/docs/adapters/supabase)
for the full TLS setup.
:::

For what each transport supports, see [docs/capabilities](/docs/capabilities)
or the [capabilities table](/capabilities) on this site.
